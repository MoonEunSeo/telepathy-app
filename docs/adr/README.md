# Architecture Decision Records

ADR은 이미 내려진 중요한 기술 결정을 코드와 함께 보존한다.

## 상태

- `제안됨`: 검토 중
- `수락됨`: 구현 기준으로 확정
- `폐기됨`: 선택하지 않음
- `대체됨`: 새 ADR이 이전 결정을 대체

| [002](002-redis-state-boundary.md)        | Redis 휘발성 상태 경계       | 수락됨 |
| [003](003-capacitor-auth.md)              | Capacitor 번들·인증 전략     | 수락됨 |
