# .claude/issues — 기능별 로직 메모

Claude 가 작업 전에 읽는 **기능별 요약본**이다. 매 세션 리니어 전체를 여는 대신 이걸 먼저 본다.

## 규칙

1. **리니어와 이 파일이 다르면 리니어가 맞다.** 이건 요약이다.
2. 항목마다 `(TEL-29 / 2026-08-05)` 도장을 찍는다. 언제 기준인지 모르면 믿을 수 없다.
3. 리니어에 쓸 때 이 파일에도 **같이** 쓴다. 나중에 몰아 쓰면 반드시 어긋난다.
4. 여러 기능에 걸리는 항목은 **각 파일에 중복으로 적는다.** 고칠 때 양쪽 다 고친다.
5. 진행률·담당자·일정은 안 적는다. 리니어가 관리한다.
6. 코드를 읽으면 아는 내용은 안 적는다. **왜 그렇게 됐는지**를 적는다.
